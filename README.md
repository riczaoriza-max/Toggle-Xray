# Toggle X-Ray

Toggle X-Ray is a lightweight, client-side Fabric mod for Minecraft that lets you instantly switch X-Ray vision on or off with a single keybind. It is designed for fast toggling, clarity, and minimal performance overhead.

## Overview

- **Mod name:** Toggle X-Ray
- **Minecraft version:** 1.20.1
- **Mod loader:** Fabric
- **Side:** Client-side
- **Author:** kotoritos
- **Language:** English (all user-facing text and documentation)
- **Project page:** <https://www.curseforge.com/members/kotoritos/projects>

## Main Feature

### X-Ray Toggle System

- Press **F6** to enable X-Ray vision.
- Press **F6** again to disable X-Ray and return to the default view.
- The toggle works instantly with no restart required.

### X-Ray Vision

When X-Ray mode is enabled, most common blocks become transparent or hidden, allowing valuable blocks such as ores to be clearly visible through the terrain. Disabling X-Ray restores Minecraft’s normal rendering.

## Keybind

- **F6** — Toggle X-Ray ON / OFF

> The keybind can be changed in the Minecraft controls menu.

## Design Philosophy

- Simple one-key toggle
- No menus or complex configuration
- Lightweight and performance-focused
- Instant enable/disable with full visual restoration
- Optimized for fast switching and minimal visual disruption

## Compatibility

- Minecraft Java Edition **1.20.1**
- Requires **Fabric Loader** and **Fabric API**
- **Client-side only**
